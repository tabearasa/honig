# honig 🍯

Super-small website for QR-Codes on honey glasses.

> [!WARNING]
> I really don't care about the style and structure in this
> project as it serves a very limited scope.
> This warning is also a reminder to myself, that I should never
> do anything fancy here! There are more important projects for
> me. This is just fun.

## Bienen-Buzz-Facts

Every glass comes with a "Bienen-Buzz-Fact". If you want to get
spoiled, you can read these already in the
[`buzz-facts.csv`](data/buzz-facts.csv).

## Local Development

Stupid reminder for me and any agent. This project is completely
static and can be run by a simple python server.

```bash
python -m http.server -b 127.0.0.1 8000
```
